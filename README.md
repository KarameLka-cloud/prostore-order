# Товарный чек — Простор

Миниприложение на Flet для оформления товарного чека по образцу ИП Клименко и выгрузки в DOCX.

## Запуск

```bash
cd /Users/valentin/Desktop/order-prostor
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Документы сохраняются в `Товарные чеки/`. Реквизиты продавца — в `seller.py`.
